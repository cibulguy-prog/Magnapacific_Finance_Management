# Magna Pacific — הפעלה כאתר עם Google Sheets כמקור אמת

## מה יש בחבילה הזו

```
index.html          ← האתר עצמו (עמוד הבית)
app.js               ← כל הלוגיקה של האפליקציה
gas/Code.gs           ← קוד ה-Google Apps Script (השרת הקטן שהופך את הגיליון ל-API)
gas/SeedData.gs       ← הנתונים ההיסטוריים, מוכנים להטענה חד-פעמית לגיליון
```

## שלב 1 — להעלות את `index.html` ואת `app.js` ל-GitHub

בעמוד הראשי של הריפו שלך (`Magnapacific_Finance_Management`):
1. לחצו על **Add file → Upload files**.
2. גררו את `index.html` ואת `app.js` (רק את שני אלה, בלי תיקיית `gas`) לתוך החלון.
3. Commit changes.

## שלב 2 — להפעיל GitHub Pages

1. בריפו: **Settings → Pages**.
2. תחת "Build and deployment" → Source: **Deploy from a branch**.
3. Branch: **main** (או master), תיקייה: **/ (root)**.
4. שמרו. אחרי דקה-שתיים תקבלו קישור בסגנון:
   `https://cibulguy-prog.github.io/Magnapacific_Finance_Management/`
   זה יהיה הקישור הקבוע לאפליקציה שלכם — אפשר לשמור אותו כמועדף.

בשלב הזה האתר כבר יעבוד, אבל עדיין רק עם הנתונים ההתחלתיים המוטמעים בו (שינויים לא יישמרו). זה מתוקן בשלבים הבאים.

## שלב 3 — ליצור את הגיליון ואת ה-Apps Script

1. פתחו [sheets.google.com](https://sheets.google.com) וצרו גיליון חדש וריק. תנו לו שם, למשל "Magna Pacific — Finance DB".
2. בתפריט: **Extensions → Apps Script**.
3. יפתח עורך קוד עם קובץ ריק בשם `Code.gs`. מחקו את כל התוכן שם, והדביקו במקומו את כל התוכן של `gas/Code.gs` מהחבילה הזו.
4. לחצו על ה-**+** ליד "Files" ובחרו **Script**. תנו לו בדיוק את השם `SeedData` (הוא ייצור `SeedData.gs`). הדביקו לתוכו את כל התוכן של `gas/SeedData.gs`.
5. שמרו (Ctrl+S / סמל הדיסקט).
6. מהתפריט העליון, ליד כפתור ה-Run (▶), יש תפריט נפתח לבחירת פונקציה — בחרו **importSeed** ולחצו **Run**.
7. בפעם הראשונה תתבקשו לאשר הרשאות — Google תזהיר ש"האפליקציה לא מאומתת", זה תקין (זה סקריפט שלכם, לא של גורם חיצוני): **Advanced → Go to (שם הפרויקט) (unsafe) → Allow**.
8. אחרי שה-Run מסתיים בהצלחה, חזרו לגיליון עצמו — אתם אמורים לראות שלוש לשוניות חדשות: **Income**, **Expenses**, **Categories**, מלאות בנתונים ההיסטוריים.

## שלב 4 — לפרסם את ה-Web App

1. בעורך ה-Apps Script: **Deploy → New deployment**.
2. ליד "Select type" לחצו על גלגל השיניים ובחרו **Web app**.
3. הגדרות:
   - **Execute as:** Me
   - **Who has access:** Anyone
4. **Deploy**. אשרו הרשאות שוב אם מתבקש.
5. תקבלו **Web app URL** — קישור ארוך שמתחיל ב-`https://script.google.com/macros/s/.../exec`. **העתיקו אותו**.

> חשוב: בכל פעם שתשנו את הקוד ב-`Code.gs` בעתיד, צריך **Deploy → Manage deployments → ✎ (Edit) → New version → Deploy** כדי שהשינוי ייכנס לתוקף. הקישור עצמו לא משתנה.

## שלב 5 — לחבר את האתר לגיליון

1. ב-GitHub, פתחו את `app.js` (עריכה ישירה בדפדפן: לחצו על סמל העיפרון).
2. חפשו את השורה הזו בראש הקובץ:
   ```js
   const APPS_SCRIPT_URL = "PASTE_YOUR_APPS_SCRIPT_WEB_APP_URL_HERE";
   ```
3. הדביקו במקום הטקסט את ה-Web App URL שהעתקתם בשלב הקודם, בין המרכאות.
4. Commit changes.

תוך דקה GitHub Pages יעדכן את האתר אוטומטית. רעננו את הדף — האפליקציה תיטען עכשיו ישירות מהגיליון, וכל שינוי (שורה חדשה, עריכת תא) יישמר בו אוטומטית.

## דברים שכדאי לדעת

- **אין ניגוד גרסאות חכם.** אם תערכו את הגיליון ידנית ובו-זמנית מישהו עורך באתר, השמירה האחרונה מנצחת ודורסת את הקודמת. מומלץ: לא לערוך את הגיליון ידנית תוך כדי שהאתר פתוח אצל מישהו, אלא רק דרך האתר עצמו.
- **גישה לגיליון עצמו** (לצפייה ישירה, גיבויים, וכו') נשארת פתוחה לכם דרך Google Sheets הרגיל — זה עדיין הגיליון שלכם, האתר רק קורא וכותב אליו.
- **הנתונים ההתחלתיים המוטמעים ב-`index.html`** משמשים רק כגיבוי אם האתר לא מצליח להתחבר לגיליון (למשל אין אינטרנט) — ברגע שהחיבור עובד, תמיד רואים את הנתונים העדכניים מהגיליון.
